# Project-Finder

Project-Finder is a tool designed to help you quickly locate your projects based on filenames or text inside files. This can be particularly useful for developers who manage multiple projects and need an efficient way to search through them.

## Features

- **Search by Filename**: Quickly find projects by searching for specific filenames.
- **Search by Text**: Locate projects by searching for specific text within files.
- **User-Friendly Interface**: Easy-to-use interface for seamless searching.

## Usage

To use A-Project-Finder, run the following command:
```bash
python a_project_finder.py
```

Then, follow the on-screen instructions to search for your projects.

## Build Your Own Version

You can build your own executable version of A-Project-Finder using the `pyinstaller` library. Run the following command:
```bash
pyinstaller --onefile a_project_finder.py
```
This will generate an executable file in the `dist` directory.
